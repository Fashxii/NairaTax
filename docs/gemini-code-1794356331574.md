# TASK SPECIFICATION: Integrate NRS Rev360 & E-Invoicing Engine into DIYtax9ja (NairaTax)

> **Implementation status:** Phases 1–4 built on Firestore (not Prisma/Next.js). See [NRS_REV360_IMPLEMENTATION.md](./NRS_REV360_IMPLEMENTATION.md) for what was built, decisions, and the backlog (OCR, e-invoicing, Rev360 API).

You are tasked with implementing the backend models, transformation pipelines, tax compliance shields, and export engines for DIYtax9ja (Next.js PWA / Firebase / Cloud Functions). 

This system acts as a middleware preparation layer bridging Open Banking transactions and OCR receipt logs directly into Nigeria Revenue Service (NRS) Rev360 schedules (Form VAT 002 Schedules A & C, CIT exemptions, and WHT deduction schedules).

Follow the implementation roadmap below in sequential phases.

---

## PHASE 1: Data Contracts & Database Schema (Prisma / Firestore)

Define the standard data models for raw transaction ingestion, taxpayer profiles, and pre-computed tax schedules.

### 1.1 Ingested Transaction Model (`schema.prisma`)
```prisma
enum TxType {
  CREDIT
  DEBIT
}

enum CitExpenseCategory {
  OPERATING_EXPENSE
  CAPEX
  SALARY_PAYE
  RENT_EXPENSE
  EXEMPT_SUPPLY
  NON_ALLOWABLE
  SALES_REVENUE
  UNCLASSIFIED
}

model Transaction {
  id                  String             @id @default(uuid())
  userId              String
  accountId           String
  aggregatorTxId      String             @unique // Open Banking ID (Mono / Okra)
  amountKobo          BigInt             // Stored in Kobo to eliminate floating-point error
  type                TxType
  date                DateTime
  narration           String
  counterpartyName    String?
  counterpartyTaxId   String?            // 13-digit validated NRS / JTB TIN
  invoiceRef          String?
  isVatable           Boolean            @default(false)
  vatRate             Float              @default(0.075) // 7.5% Nigerian statutory VAT
  citCategory         CitExpenseCategory @default(UNCLASSIFIED)
  documentProofUrl    String?            // Storage URL for OCR scanned receipt
  createdAt           DateTime           @default(now())

  user                User               @relation(fields: [userId], references: [id])
  @@index([userId, date])
  @@index([counterpartyTaxId])
}

model TaxpayerProfile {
  id                  String             @id @default(uuid())
  userId              String             @unique
  businessName        String
  taxId               String             @unique // 13-digit NRS TIN
  nin                 String?
  bvn                 String?
  rcNumber            String?
  stateOfResidence    String             // SIRS jurisdiction routing (e.g. LIRS, OGSIRS)
  annualTurnoverKobo  BigInt             @default(0)
  isSmeExempt         Boolean            @default(false) // Turnover threshold evaluation
  user                User               @relation(fields: [userId], references: [id])
}
